#Описание проекта
В данной лабораторной работе создаётся прототип top-down шутера. 
Он состоит из игорового поля и игрока, который может делать выстрелы.
Перемещение осуществляется с помощью клавиш WASD, выстрелы - Space или ЛКМ.
Выстрел происходит из центра игрока в направлении его взгляда, а после покидания экрана пуля уничтожается.

#Сцены
В проекте 3 сцены: Player, Grass, Bullet.
Сцена Grass является основной, на ней располгается игрок, который может делать выстрелы.

#Скрипты в проекте

##Player
У игрока есть 4 переменные: скорость, перезарядка выстрелов, пуля, таймер для перезарядки.
Игрок появляется на поле при запуске игры.
Также у игрока есть 3 функции: _ready(), _input(), _process().

**_ready()**
В этой функции идёт запуск автостарта таймера для перезарядки пули. 
Это происходит 1 раз при запуске игры.

**_process()**
В этой функции происходит взаимодействие с самой игрой, не требующие мнгновенного отклика, то есть:
	- игрок двигается вверх/вниз/влево/вправо или делает выстрел
	- это считывается соответствующими командами
	- в зависимости от этого он перемещается по полю

Отдельный момент: *look_at(get_global_mouse_position())*.
С помощью этой команды спрайт игрока поворачивается за мышкой в процессе игры.

**_input()**
В этой функции реализовываются мнгновенные отклики игры:
	- реакция на выстрелы 
	- реакция выход из игры 
	
##Bullet
В пуле хранится 1 переменная: скорость её движения.
Пуля вылетает из середины квадата (игрока) в направлении его взгляда и по нажатии соответствующей клавиши.
Также в пуле хранится 3 функции: _ready(), _process(), on_area_2d_area_entered().

**_ready()**
На данный момент это функция-заглушка, которая ничего не выполняет.

**_process**
В этой функции задаётся вектор полёта пули.

**on_area_2d_area_entered**
При столкновении с краем игрового поля пуля должна самоуничтожаться.
Функция реализовывает эту механику.

##Grass
В траве находится 1 переменная: игрок.
Трава является игровым полем и в начале игрок появляется на нём. 
Также реализованы 2 функции: _ready(), _process().

**_ready()**
В этой функции задаётся появление игрока на поле.

**_process**
Функция-заглушка, которая ничего не реализовывает.
